# BuildManager

《黑神话：悟空》配装方案管理模组：把当前整套装备存成方案，之后一键换回。

Save and re-apply complete loadouts in Black Myth: Wukong — weapons, armor, curios, spirits, gourds, wine, soaks, and spells in one click.

- 当前版本：**0.12.31**
- Nexus Mods：[BuildManager - Instant Full Gear Swap](https://www.nexusmods.com/blackmythwukong/mods/1551)
- 支持语言：简体中文、繁体中文、英语、日语、韩语（其他语言回退英语）

## 功能

- **多套方案**：默认 10 个槽位，最多 14 个；可保存、应用、重命名、清空、删除。
- **整套换装**：武器、防具、珍玩、法宝、精魄、葫芦、酒与泡酒物、法术一并保存和还原；空槽也会被精确还原。
- **缺失保护**：应用时如果当前存档缺少方案里的道具，只跳过缺失项，其余照常换装，并在游戏内提示缺了哪些。
- **物品详情**：焦点停在物品格上时显示与原版装备页一致的名称、属性、独门妙用、背景故事和套装效果。
- **键鼠 + 手柄**：完整支持手柄导航，所有获得焦点的按钮都有金色边框。
- **多语言**：默认跟随游戏语言，也可在面板右上角的“设置”里手动指定。

## 环境要求

- 《黑神话：悟空》PC 版
- [CSharpLoader with hook v0.1.0](https://www.nexusmods.com/blackmythwukong/mods/664)（本模组不自带加载器）

## 安装

1. 先安装 CSharpLoader：把 `version.dll` 放到 `b1\Binaries\Win64\`，把 `CSharpLoader\` 文件夹放到同一目录。
2. 下载本模组的压缩包，解压到**游戏根目录**（与 `b1` 同级），选择合并文件夹。
3. 启动游戏。进入装备页后，第一行会出现“配装”按钮。

安装后的文件位于：

```
b1\Binaries\Win64\CSharpLoader\Mods\BuildManager\
    BuildManager.dll
    data\            静态数据表
    data\locale\     分语言物品文本
    lang\            UI 文案（可自行修改）
    presets\         你的配装方案（覆盖安装不会删除）
```

升级时直接用新压缩包覆盖即可；`presets\` 是你的存档数据，不会被覆盖。

## 使用

1. 打开装备页（土地庙或任意可换装处），点击第一行的 **配装**，或用手柄聚焦后按 `A`。
2. 左侧是方案列表，右侧预览该方案的完整配装。
3. 点击方案（手柄 `A`）锁定后，动作按钮才可用：

| 按钮 | 作用 |
|---|---|
| 保存当前 | 把当前身上的配装写入所选方案 |
| 应用 | 换成所选方案（战斗中/剧情中会被游戏拦下） |
| 清空 | 删除方案内容，保留空槽位 |
| 删除 | 删除该槽位，后面的方案整体前移 |
| 重命名 | 双击方案行、按 `Y`，或点击该按钮 |

4. 面板右上角的 **设置** 可以切换语言；默认“跟随游戏语言”。
5. 返回：`B` / `Esc` / 右键 / “返回”按钮。若已选中方案，第一次返回只取消选中，再按一次才关闭面板。

### 手柄操作

| 按键 | 作用 |
|---|---|
| 方向键 / 左摇杆 | 移动焦点；左右可在方案列表、物品格、设置按钮之间切换 |
| `A` | 锁定/取消锁定方案，或执行当前动作按钮 |
| `Y` | 重命名所选方案 |
| `B` | 取消选中 / 关闭面板 |

## 语言

| 语言 | 说明 |
|---|---|
| 简体中文 / 繁体中文 / 英语 / 日语 / 韩语 | 完整界面与物品文本 |
| 其他语言 | 自动使用英语 |

默认跟随游戏语言。如果游戏是英文而你想看中文（或反之），在设置里手动选择即可，物品名称和描述会一起切换，不需要重启游戏。

## 常见问题

**提示“当前场景不允许换装”**
游戏自身的限制：战斗中、剧情中或部分特殊场景不能换装。回到安全场景再试。

**提示缺少道具**
方案里有当前存档没有的装备/珍玩/法术等。缺失项会保持原样，其余正常应用。跨存档使用方案时最常见。

**更新游戏后模组失效**
游戏大版本更新可能改变内部结构，需要等待模组更新。请保留 `presets\` 文件夹，升级模组不会影响方案。

**想备份方案**
把 `CSharpLoader\Mods\BuildManager\presets\` 整个文件夹复制走即可；`slots.json` 保存槽位数量与自定义名称。

**卸载**
删除 `CSharpLoader\Mods\BuildManager\` 文件夹即可。如需保留方案，先备份 `presets\`。
